# One-Liner Laughs

This program writes one funny one-liner to `entry.txt` for the make.fun bounty `u-coral-404-one-liner-laughs-aa872d41`.

## How to Run

```bash
MAKEFUN_OUTPUT_DIR=out node main.ts
```

## Constraints

- The joke must be 1-200 characters.
- The joke must be a single line.
